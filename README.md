# VLA は指示に従っているか — 同じ場面で「置け」と「取り出せ」を入れ替えて検証する

ロボットの操作を言葉で指示する VLA（Vision-Language-Action）モデル π0.5 を、シミュレータ（LIBERO / robosuite / MuJoCo）の中で追加学習した。
人の手本には「置く」課題はあるが、「容器から取り出して机に置く」課題が無い。そこで、シミュレータの本当の物の位置を読む教師の script に手本を作らせ、
学ぶ部分（LoRA を当てるブロック）を替えて学ばせた。

このリポジトリは、その試みのうち、手元の GPU（RTX 5090）1 枚で学習・評価した部分のコードの抜粋である（Physical AI 講座の最終課題）。

## 問いと結果

同じ初期状態・同じ乱数の seed で、指示文だけを逆にした対（「put the black bowl on the left plate」⇔「take the black bowl off the right plate and place it on the table」など）を 25 場面で作り、次の 3 つを調べた。

比べ方: 評価は同じ初期状態・同じ seed なら決定的に同じ動きをする（同じ重みを同じ指示で 2 回回すと、25 場面すべてで指令と物の位置が bit まで同じだった）。
2 つの重みは試行ごとに対にして、「片方だけ成功した数」b・c を数え、b と c の差が 2√(b+c) を超えるかを差の目安にした。

**Q1 指示に従っているか。** 教師の手本を使わずに学んだ基準の重み（S。人の手本と、学習途中のモデルが成功した試行で学んだ）は、25 場面すべてで、「置け」でも「取り出せ」でも机の鉢を動かした。
指示文で手先の道筋は少し変わる（同じ時刻の手先の差の中央値 2.0 cm）が、する課題は変わらない。取り出せの成功は 0/25。

**Q2 どこを学べば、指示に従い、できるようになるか。** 教師の手本（置け・取り出せを同じ初期配置の対で含む）で、学ぶ部分だけを替えた。
評価は「容器の黒い鉢を取り出して机に置け」の 68 場面（皿 34・トレイ 34。学習の場面とは初期配置が違う）。どれも 500 step の時点の重み。
成功は評価器の判定で、鉢が机に触れた時点で出る（鉢は掴んだまま。指を開いて離すところまでは測っていない）。

| 学ぶ部分（LoRA を当てるブロック） | 取る 68 本 | 皿 | トレイ |
| --- | --- | --- | --- |
| S（教師の手本なし。比べの基準） | 0/68 | 0/34 | 0/34 |
| 動作だけ（action expert、rank 8） | 0/68 | 0/34 | 0/34 |
| 画像と動作（rank 16） | 9/68 | 2/34 | 7/34 |
| 動作と言語（言語注意・言語mlp を足す、rank 16） | 48/68 | 14/34 | 34/34 |
| 5 ブロック（画像注意・画像mlp・動作・言語mlp・言語注意、rank 16） | 49/68 | 15/34 | 34/34 |

言語の側を学ぶと取り出せるようになった。5 ブロックと動作と言語は、片方だけ成功 3・2（幅 4.47）で差が無く、画像の 2 ブロックは要らなかった。
ただし、取り出しを覚えた代わりに「置け」が崩れた。逆の指示の 25 場面で、置けの成功は S 20 に対して動作と言語 10・5 ブロック 7
（S だけ成功 11・13、幅 6.9・7.2）。5 ブロックは「置け」と言われても 15 場面で容器の鉢を取りに行った。

**Q3 従えるようになった指示は、別の容器へ移るか。** 5 ブロックで、教師の手本から「トレイから取る」手本だけを外して学ぶと、トレイは 34/34 → 0/34
（片方だけ成功 34・0、幅 11.66）、皿も 15 → 8 に下がった。トレイの 34 場面では、机の鉢をトレイへ運んだ 15・トレイごと持ち上げた 7・
大きくは動かない 11。皿から取る動きと、置く先としてのトレイは、それぞれ学んでいても、自動では組み合わさらなかった。

限り: 学習の seed は 1 つ、評価の seed も 1 つ（別の seed での揺れは測っていない）。比べた 500 step は学習の途中（学習率はまだ 8.9e-5 と高い）。
逆の指示の対は、学習した型の場面の 25 だけ。

## 中身

コードは、使った時点の版をそのまま写した（git の履歴で、使った後に変更が無いことを確かめた）。どの元のファイルから写したかは [MANIFEST.tsv](MANIFEST.tsv) にある。
ファイルの中の説明は日本語。

| 置き場 | 役 |
| --- | --- |
| `data-gen/teacher/` | 教師の script（`scripted.py`）。シミュレータの物の位置と姿勢を読み、掴む点・持ち上げ・運ぶ先を計算して動かす。`run2/lib.py` は評価器と同じ手順で記録を流し直す部品 |
| `data-gen/pairs/` | 対の場面を作る。`scenes.py` が、物と置き場と初めの置き方が同じで、指示文と目標だけが違う 2 つの課題定義（BDDL）を作り、`pairgen.py` が初期状態を作って教師に解かせる |
| `data-gen/retime/` | 教師の動きを、人の手本に近い速さへ引き直す（`plan.py`・`follow.py`）。底で止まってから閉じる間と、掴む点の深さの設定（`p4-s8-*.json`）。`rt_replay.py` は引き直した指令の流し直し、`render.py` はカメラ画像の描画（CPU、OSMesa、256×256） |
| `data-gen/dataset/` | 流し直した手本を LeRobot v3.0 の形の dataset に束ねる（`dshost_dwell.py`）。`mix_stage.py` は 2 つの深さの手本を 1 つの dataset へ段取りする |
| `train/tools/` | π0.5 の LoRA を container の中で学習する包み（`train`）と、学ぶ部分の表（`train-blocks*.tsv`。ブロックごとの module の正規表現・module 数・parameter 数・rank） |
| `train/entry/` | lerobot-train の入口への差し込み。2 組（人の手本・教師の手本）を窓ごとに決めた並びで出す sampler、LoRA の alpha、損失から episode の終わりを越えた時刻を外す forward |
| `train/bundle/` | 人の手本と教師の手本を 1 つの dataset に束ね、全件を照合し、組の番号と外す本を作る。`make_groups_e1.py` は「トレイから取る」手本だけを外す版 |
| `train/runs/` | 5 つの学習の起動 script（動作だけ・画像と動作・動作と言語・5 ブロック・トレイから取るを外した 5 ブロック）。起動の前に、学習する parameter の数・入口と道具の指紋・dataset の本数を照合する |
| `analysis/` | 評価の記録（試行ごとの npz）を読む。`tables.py` は重みごとの成功の数と、試行ごとの対の比べ。`verb_swap.py`・`verb_target.py` は逆の指示の対で、どちらの鉢を動かしたか。`tray_moves.py` はトレイの場面で何が動いたか。`make_verbswap_sets.py` と `ledger/` は逆の指示の評価の課題集合 |
| `video/` | 評価の記録を、評価器と同じ手順・同じ指令で流し直し、カメラだけを 512×512 にして撮り直す（`render_trials.py`）。記録と 1 mm 以内で一致した試行だけを動画に使う |

container の中の置き場（script の中の `/g`・`/s2` など）と、この README の置き場の対応:
`/g` = `data-gen/teacher/`、`/g/run2` = `data-gen/teacher/run2/`、`/s2` = `data-gen/pairs/`、`/s5` = `data-gen/retime/`。

## 動かすには

単体では動かない。コンペの配布の Docker image（LIBERO-plus・robosuite・MuJoCo・lerobot 0.4.4 入り）と、π0.5 の元の重み、
人の手本の dataset が要る。重み・dataset・評価の記録は入れていない。script の中の絶対パスは、作った計算機の物のまま残した。

## 公開にあたって変えた所

コンペの配布物（評価の例題）と運営の回答の中身に触れたコメントと文字列を、6 か所伏せた（`data-gen/pairs/scenes.py` 5 か所・
`data-gen/teacher/scripted.py` 1 か所）。`scenes.py` の `EXCLUDED_SCENES`・`EXAMPLE_COMBOS`（例題と重なる場面と組み合わせ）は中身を空にした。
ほかの行は元のまま。伏せた行があるファイルは、MANIFEST.tsv の sha256 が元と違う。
